Welcome to **100 Days of LeetCode** — a focused, creative, and consistent journey to sharpen problem-solving skills through daily coding practice.

## ✨ Why this repo
- Build a long-term habit of structured problem solving.
- Track progress with a daily log and a concise archive of solutions.
- Keep motivation high with small, visible wins.

## 🧭 The challenge
- **Start date:** 12-12-2023
- **Duration:** 100 days (or 3 months)
- **Goal:** One meaningful solution per day, with clear notes.

## 📦 Repo layout
```
.
├── docs/                  # Challenge notes and roadmap
├── progress/              # Daily logs and reflections
├── templates/             # Reusable solution templates
├── solutions/             # Solutions by day or topic (create as you go)
├── README.md              # You are here
└── 1_1464...cpp            # Initial solution seed
```

## 🗺️ Roadmap
Check the full roadmap and milestones here: [docs/roadmap.md](docs/roadmap.md)

## ✅ Progress tracker
Use the log file to capture daily wins, learnings, and next steps: [progress/progress.md](progress/progress.md)

## 🧰 Tech stack
- **Primary:** C++
- **Optional:** Python (for quick experiments)

## 🧪 How to use
1. Create a solution file in `solutions/` (or keep at repo root if preferred).
2. Add a short note in `progress/progress.md`.
3. Use the template from `templates/solution-template.cpp` for consistency.

## 🧱 Branching strategy (suggested)
- `main`: stable progress
- `day-XX`: daily work branches
- `feature/*`: experiments or tooling improvements

## 🌟 Inspiration
Progress is the reward. Small steps every day become massive growth over time.
